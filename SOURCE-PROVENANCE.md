# Source provenance / Provenance des sources

These public browser editions start a new public history on 28 October 2026.
They derive from the Casholoco source snapshot `7b7164fcfe442d1966a5bc28dc45951e1219daaa`.
The original repository and its private history are retained separately. This
repository is not an automatic mirror. The economic core was copied unchanged;
local authority, browser persistence and direct peer transport are added around it.

Ces éditions commencent un nouvel historique public le 28 octobre 2026. Le dépôt
et l’historique privés d’origine sont conservés séparément. Les règles et paramètres
économiques du moteur ne sont pas rééquilibrés dans ces éditions.
